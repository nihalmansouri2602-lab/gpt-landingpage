# GPT Landing Page

## Project Overview

GPT Landing Page is a modern web application developed using Next.js, Firebase, and Tailwind CSS. The goal of this project is to create a responsive and user-friendly website that presents GPT-related services while allowing users to create an account, sign in, and sign out securely.

## Technologies Used

### Next.js

I used Next.js because it provides fast performance, SEO optimization, server-side rendering, and an organized file-based routing system. It also integrates easily with React and works perfectly with Vercel deployment.

### Tailwind CSS

Tailwind CSS was used to build a modern and responsive user interface quickly while keeping the code clean and maintainable.

### Firebase

Firebase was used as the backend service to manage user authentication, including Sign Up, Sign In, and Sign Out functionalities.

### GitHub

GitHub was used for version control, source code management, and project backup.

### Vercel

Vercel was used to deploy the application online and automatically update the website whenever new changes are pushed to GitHub.

## Project Development Steps

1. Created the project using Next.js.
2. Designed the landing page interface with Tailwind CSS.
3. Created and configured a Firebase project.
4. Connected Firebase Authentication to the application.
5. Implemented Sign Up, Sign In, and Sign Out features.
6. Stored Firebase configuration in environment variables.
7. Uploaded the project to GitHub using Git.
8. Deployed the application on Vercel.

## Project Structure

### package.json

Contains project information, dependencies, scripts, and package versions such as Next.js, React, Firebase, Tailwind CSS, and TypeScript.

### public

Stores static files including images, icons, logos, and other assets used in the website.

### src

Contains the main source code of the application.

#### src/app

Contains pages and routes such as the Home page, Sign In page, and Sign Up page.

#### src/components

Contains reusable components such as the Navbar, Hero section, Footer, and authentication components.

#### src/lib

Contains utility files and Firebase configuration.

#### src/types

Contains TypeScript type definitions used throughout the project.

### .env.local

Stores Firebase environment variables and configuration keys securely.

## Conclusion

This project demonstrates the development of a modern web application using Next.js, Firebase, and Tailwind CSS. It includes a responsive design, secure authentication system, version control with GitHub, and deployment through Vercel. The project follows a structured architecture that improves maintainability, scalability, and overall development efficiency.
